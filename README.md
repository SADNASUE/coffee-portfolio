# Портфолио: Дизайн-концепты для кофейни «Тёплый угол»

Это учебный проект, демонстрирующий возможности разработки и использования AI-инструментов (Claude Code) для создания сайтов под единым брифом. 

Задача: показать, как один и тот же контент можно реализовать в абсолютно разных стилях, используя чистый HTML/CSS/JS без фреймворков.

## 🎨 Реализованные концепты:

1. **[Glassmorphism + 3D (Apple-style)](https://iphonelike-coffee.netlify.app)**
   - Плавные 3D-наклоны карточек за мышью.
   - Использование `backdrop-filter` и сложных градиентов.
   - Оптимизировано для мобильных устройств (отключение тяжелых эффектов через `@media (hover: none)` для 60 FPS).

2. **[Нео-брутализм](https://neo-coffee.netlify.app)**
   - Многостраничный сайт (Главная, Меню, Контакты).
   - Кастомный календарь бронирования (Flatpickr), переопределенный под жесткий стиль.
   - Работа с фильтрацией контента на JS.

3. **[Премиум / Editorial](https://premium-coffee1.netlify.app)**
   - Журнальная типографика (шрифты с засечками).
   - Акцент на воздух и строгую сетку.
   - Сложная форма бронирования в стиле дорогого отеля.

4. **[Классический лендинг](https://warm-coffee-1-page.netlify.app)**
   - Светлый, уютный дизайн.
   - Акцент на анимациях появления при скролле.

## 🛠 Стек технологий:
- HTML5 (Семантическая верстка)
- CSS3 (Grid, Flexbox, CSS-переменные, анимации, адаптив)
- JavaScript (Vanilla JS, IntersectionObserver для анимаций, маски ввода)
- Git / GitHub
- Хостинг: Netlify

## 🤖 Использование AI:
Код генерировался с помощью AI-ассистента (LLM). Я выступал в роли технического специалиста: ставил задачи, интегрировал код в проект, тестировал результат в браузере (включая режим эмуляции мобильных устройств) и исправлял баги. 
*Примеры ручной доработки:*
- Исправление багов адаптивности и верстки (например, бесшовная анимация бегущей строки на широких экранах).
- Кастомная стилизация сторонних библиотек (полная перекраска и адаптация календаря Flatpickr под стили сайтов).
- Оптимизация производительности: отключение тяжелых CSS-эффектов (`backdrop-filter`, `blur`) на мобильных устройствах через медиа-запросы для предотвращения лагов.
- Настройка деплоя проектов на Netlify.
